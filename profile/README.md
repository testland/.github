# Testland

Testland makes quality engineering tools for software teams.

## [testland/qa](https://github.com/testland/qa)

A Claude Code plugin marketplace of reviewed QA skills and agents. It covers test automation, API, performance, security, accessibility, mobile and manual testing. The skills also install into Cursor, Copilot, Gemini and other coding agents through [skills.sh](https://skills.sh/testland/qa).

```
/plugin marketplace add testland/qa
/plugin install qa-starter@testland-qa
```

Every skill and agent is reviewed against a six-dimension rubric before merge, and uncited claims are rejected.
